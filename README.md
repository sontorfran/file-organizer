# Python File Organizer 📁

A simple Python automation tool that organizes files into folders based on their extensions.

## Features

- Automatically organizes images, documents, and music files.
- Supports JPG, PNG, PDF, TXT, and MP3 files.
- Handles duplicate filenames without overwriting existing files.
- Includes a Preview Mode to see changes before moving files.
- Validates folder paths and asks for confirmation.
- Displays a summary of organized and unsupported files.

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

   `python main.py`

5. Enter the folder path you want to organize.
6. Choose Preview Mode or Normal Mode and confirm the operation.

**Note:** The program moves files in the selected folder, so use Preview Mode first.
